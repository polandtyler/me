## Phase 1: Strengthen Foundations (Months 1-3)
**Goal:** Refresh the essential mathematics, programming, and computer science concepts needed for machine learning.

![phase-1-core-ml](https://github.com/user-attachments/assets/d0d797f3-1de9-4c93-a588-05708caff0fe)

#### Maths
 -  Brush up on Linear Algebra
	 - [ ] Vectors
	 - [ ] Matrices
	 - [ ] Matrix multiplication
	 - [ ] eigenvalues
	 - [ ] SVD
	 - [Khan Academy Linear Algebra Fundamentals](https://www.khanacademy.org/math/linear-algebra)
 - Review Calculus concepts
	 - [ ] Derivatives
	 - [ ] Gradients
	 - [ ] The chain rule (for understanding optimization algorithms like backpropagation)
	 - Khan Academy (Calculus I & II basics)
	 - [3Blue1Brown Calculus intuition](https://www.3blue1brown.com/topics/calculus)
 - Stats
	 - [ ] Basic probability distributions
	 - [ ] Bayes theorem
	 - [ ] Expectation
	 - [ ] Variance
	 - [ ] Hypothesis testing
	 - [ ] Statistical significance
	 - Khan Academy (Probability, Descriptive Stats)
	 - [StatQuest](https://www.youtube.com/c/joshstarmer)
	 - [Mathematics for Machine Learning](https://www.coursera.org/specializations/mathematics-machine-learning)
	 - [GeeksForGeeks Guide to ML Math](https://www.geeksforgeeks.org/machine-learning/machine-learning-mathematics/)

#### CS Fundamentals
- [ ] Efficient handling of large data sets
- [ ] Brush up on collections (array, tree, hash maps, etc) and their algos
- [Grokking Algorithms](https://learning.oreilly.com/library/view/grokking-algorithms/9781617292231/)

#### Learn Python
- Syntax and conventions
- ML Core libraries
	- [ ] NumPy (for matrix operations)
	- [ ] pandas (for data wrangling)
- [ ] Google ML Crash Course - work through [this](https://developers.google.com/machine-learning/crash-course/prereqs-and-prework)
- [ ] [Python for everybody](https://www.coursera.org/specializations/python/)(U Michigan)
- [ ] [Machine learning specialization (Coursera)](https://www.coursera.org/specializations/machine-learning-introduction)

## Phase 2: Core ML (Months 4 – 6)

![phase-2-core-ml](https://github.com/user-attachments/assets/b27c2618-a40c-477d-bc11-9509d69d49ab)

**Goal:** Build a thorough understanding of fundamental machine learning algorithms and practices, and apply them to simple projects.

![](phase-2-core-ml.png)

#### Supervised Learning
- Linear & logistic regression
- Classification
	- [ ] Decision trees
	- [ ] Random forests
	- [ ] Support vector machines
	- [ ] k-nearest neighbors
-  Key concepts
	- [ ] Loss functions
	- [ ] Model training
	- [ ] Over / under fitting
	- [ ] Regularization
	- [ ] Evaluation metrics
		- [ ] Accuracy
		- [ ] Precision/recall
		- [ ] RMSE
	- [ ] Conceptual understanding of how models learn from data
	- [ ] Bias-variance tradeoff
- [ ] PROJECT: Implement simple regression & classification from scratch in Python

#### Unsupervised Learning
- Clustering
	- [ ] k-means
	- [ ] Hierarchical clustering
	- [ ] Dimensionality reduction (PCA) techniques to explore non-annotated data
-  PROJECT: Practice with clustering
	- [ ] Apply PCA on a dataset to practice reduction techniques
	- [ ] Implement a clustering algo to find natural groupings in a dataset (customers by behavior, etc)

#### Fundamental ML Concepts
- Feature engineering - transform raw data into meaningful input
	- [ ] Handle missing data
	- [ ] Categorical encoding
	- [ ] Feature scaling
- Model validation - Make sure models generalize well
	- [ ] Deciding on train / test split
	- [ ] Cross-validation
	- [ ] Hyperparameter tuning (grid search, etc)
- Deeper look into probability & stats in ML
	- [ ] Probability distribution of errors
	- [ ] Confidence intervals
	- [ ] Model A/B testing

#### Solidify Learnings
- E2E ML Pipeline that includes
	1. Data cleaning
	2. Exploratory analysis
	3. Model training
	4. Model evaluation
- Using Jupyter notebook to combine code, results, explanations
	- Version control in Github

**Timeframe:** Aim to complete 1–2 online courses and 2+ small projects in this phase (about 3 months at ~10 hours/week). 
_If needed, extend to 4–5 months – mastering these basics is crucial before moving on._

> **Goal of Phase 2:** Have a firm grasp of core ML algorithms and how to apply them to real data. Able to discuss and implement things like linear vs. nonlinear models, evaluation metrics, and the workflow of an ML project (data preparation to model deployment in a notebook). Also have initial project(s) to showcase, demonstrating skills in data handling and classical ML.
